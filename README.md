# Hemat Berapa?

Kalkulator belanja pintar untuk membandingkan harga supermarket dan grosir. Dibuat untuk emak-emak yang ingin memastikan tidak tertipu promo palsu.

## Instalasi & Hosting

Karena ini aplikasi web statis (HTML, CSS, JS murni), Anda bisa melakukan _hosting_ secara gratis melalui GitHub Pages:
1. Buka [GitHub](https://github.com/) dan buat repository baru bernama `hematberapa`.
2. _Upload_ semua file dalam folder ini ke repository tersebut.
3. Masuk ke **Settings > Pages**.
4. Di bawah `Build and deployment`, pilih *branch* `main` dan klik **Save**.
5. Dalam beberapa menit, aplikasi web Anda bisa diakses secara global.

## Fitur
- Menghitung harga per berat/volume barang
- Dukungan simulasi harga diskon & beli banyak (Grosir / Promo)
- Tampilan Bilingual (ID / EN)
- Dark / Light theme _mobile-friendly_
- _Progressive Web App_ (PWA) bisa diinstal tanpa App Store / Play Store dan bekerja _offline_.
